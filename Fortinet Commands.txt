----------------------------------------------------Ping------------------------------------------------------------
Set the source IP/interface:
#execute ping-options source 172.16.5.215
#execute ping 172.16.5.16

Set the number of ping packets:
#execute ping-options repeat-count 5

Set packet size
execute ping-options data-size 1400


View current ping options:
#execute ping-options view-settings

Reset ping options to default:
#execute ping-options reset

To troubleshoot further common antivirus issues, you can check the information provided by the following commands:

•get system performance status: Displays statistics for the last one minute.

•diagnose antivirus database-info: Displays current antivirus database information.

•diagnose autoupdate versions: Displays current antivirus engine and signature versions.

•diagnose antivirus test "get scantime": Displays scan times for infected files.


---------------------------------------Troubleshoot IPS high CPU usage-------------------
Continious high cpu use by the ips engine is not normal, and you should investigate it, use the following command
along with the displayed options to troubleshoot the issue.

5. if there are high cpu usage by the ips engine, use this option to isolate where the problem might be, this option enables ips bypass mode, the ips engine is still running but not ispecting traffic.
If cpu usage decreases after that, it usually indicates that the volume of inspected traffic is too high for fortigate.
If cpu remains high after you enable ips bypass mode, it usually indicates a problem in the ips engine, which you must report to fortinet support.

2. you can disable the ips engine completely using option 2, to restore ips inspection of traffic after you finish troubleshooting, use option 2 again.
